# Native level-slot ownership prerequisite

This is a source-bound **existing-slot composition precondition**, not a new-level
exporter. It does not turn the ID65 laboratory into a new independent native
level, alter an existing candidate, or certify arbitrary replacement payloads.

## Existing foundations and the gap

`NativeLevelReplacementStore` / `NativeLevelSlotLocator` already bind the exact
Stone Hill replacement profile, source hashes, packed subfiles, portal rows and
Return Home rows. `Id65AuthoredCollisionMusicPlan` composes independently checked
byte producers for the fixed row80 laboratory; its publisher enforces source/CUE
freshness, protected bytes, sector integrity and atomic artifact publication.
The shared `NativeRelocationMap`, `NativeLevelDataGrowthLayout` and
`NativeSkyWadRelocator` support explicitly owned multi-subfile growth.

Disc allocation is not native identity allocation. A larger WAD does not add save
rows, late-music rows, callback cases, normal portal reachability, or independent
return/re-entry semantics. Before this prerequisite, these identity limitations
were captured in the ID65-specific progression reports, but there was no common
multi-slot ownership preflight preventing a composition request from claiming
another retail slot's resource or persistent identity.

## New API and its authority boundary

New implementation files:

- `NativeLevelSlotOwnershipSource.cs`: private-constructor exact-source capture.
- `NativeLevelSlotOwnershipContract.cs`: neutral bounded geometry/reservation
  kernel, source-independent for hostile regression fixtures.
- `Spyro.Editor.NativeLevelSlotOwnershipSmoke`: source-free and explicitly
  requested original-source checks.

Production entry is `NativeLevelSlotOwnershipSource.CaptureAsync(originalBin)`.
It hashes the same open image before and after inspection, requires the exact
661547040-byte clean-USA source SHA
`fc866b2a02e010a6658f8af2de28bb3001eb33513e5924af014e35643c6dee37`, exact ISO WAD/EXE
extents, the original WAD header, and exact native instruction/table certificates.
It does not accept a caller catalog, a claimed source hash, a receipt or any
edited/candidate BIN as source authority. Neither the original image nor its CUE
is written. This capture is not a live source lease: a later publisher must
recapture/revalidate its own source and CUE at the existing publication boundaries.

The source object creates identity-bearing original WAD and executable address
spaces. `Reserve(requests, declaredWrites, portalIntents)` atomically validates
the complete requested set. No reservation is registered globally or retained
after failure. Requests and returned lists are immutable snapshots; input order
does not affect the plan digest. A source-bound plan constructor always compiles
requests through its captured source; it cannot wrap a caller-created neutral
geometry plan and thereby promote it to source evidence.

Each `ReplaceExisting` request automatically receives its slot, continuous/save
index, overlay/data pair, seven resource extents and bounded save fields. The
caller cannot choose a different save index or resource pair. Declared writes:

- must use the exact source address-space object, reserved owner and one resource;
- cannot cross resource boundaries or overlap another declared write, including
  another write by the same owner;
- cannot claim a WAD directory entry, global native consumer code, another slot's
  bytes, or an observed portal descriptor;
- are bounded to4096 total declarations and35 reservations.

The permitted resource extents are the slot's WAD overlay and data, plus its EXE
initial-music row, late-music row, dragon target, treasure target and name-pointer
row. Owning a pointer row does **not** own its pointed-to name/resource. Equal
music values or equal name pointers do not mean the physical row storage aliases.
The complete native WAD directory is checked for physical overlap before any
reservation, so aliases with non-level resources are also rejected.

This is an ownership precondition for a future complete composition producer.
The caller must supply its complete write footprint; this helper does not inspect
replacement bytes, discover omitted writes, verify before/after payloads, apply
patches, allocate growth, prove pointer targets or certify RAM/code semantics.
For example, an owned overlay byte range is not permission to alter arbitrary
native behavior. Existing exact-stage producers, typed relocation, independent
readback and the guarded publisher remain necessary. All plan proof flags for
publication, new independent levels, payload semantics, portal retargeting and
runtime acceptance are false.

## Native identity and capacity facts

The decimal identity is validated **before** native index arithmetic. Retail IDs
are10..15,20..25,30..35,40..45,50..55,60..64. The native continuous index is
`(levelId / 10 - 1) * 6 + levelId % 10`. Accepting arbitrary IDs would alias, for
example,16 to20's index6. Source index0..34 uses paired WAD entries
`9 + index*2` / `10 + index*2`. The checked source binds Stone Hill to loaded data
entry12 at0xB93800, not its separate level-metadata entry9; Town Square data is
entry16 at0x119E000.

Exact source certificates are retained in the source object:

| Native evidence | EXE file offset | Length | Meaning |
| --- | ---: | ---: | --- |
| Decimal index and paired resource consumer |0x5E10|0x94|Index arithmetic and16-byte paired-row stride; runtime0x80015610 onward|
| Late-music consumer |0x1C594|0x70|Consumes the per-level late-music table|
| Late-music source table |0x5F85C|0x1A4|Exactly35 rows of3 u32 values|
| Save deserializer |0x49D94|0x2D0|36 non-egg rows; egg load bound18|
| Save serializer |0x4A064|0x1E4|Per-level fields and retirement copy|
| Normal portal guard |0x47900|0x24|Runtime0x80057110 has upper-exclusive65 guard|

Each source save index has visited atsave+0x40, an unresolved byte at+0x64,
dragon count at+0x88, treasure at+0xAC (stride2) and retirement at+0x10C
(stride0x20). The opaque byte is physically distinct but its semantics are not
assigned here. Egg save rows at+0xF4 exist only for indexes0..17. A requested egg
owner at index18 or later fails. No new egg writer is supplied.

Retirement storage has exactly256 bits per level. Requested persistent true
indexes must be unique within0..255. The same true index in two different native
levels is valid because it resolves to different save rows. This is **not** a
claim that all Moby counts must be at most256 or that nonpersistent objects have
unbounded capacity; runtime allocations and native producer semantics require
separate contracts.

ID65/index35 is not accepted as an independent level. Its WAD entries79/80 are
zero in retail; entry81 begins another resource. There are36 non-egg save rows
but only35 late-music rows: the would-be row35 starts at0x5FA00 and is actually
the PETEXA0..2 LBA table (`60000,84584,113448`). The normal portal guard excludes65,
no retail portal descriptor points to65, and the existing bootstrap archaeology
proves its default flight classification. `AddIndependent`, even when given an
existing ID, is refused rather than reinterpreted as replacement. Physical clone
or laboratory work does not waive these blockers.

## Observed portals versus authored intent

Capture walks the first three length-prefixed components of each native data
subfile1 to its special-surface component. It reads the bounded pointer directory
and interprets native **byte** type6 as a portal descriptor; generic parameters of
other types are not destinations. The exact source yields29 descriptors across
the six homeworlds,29 distinct retail destinations, and none for65. Their complete
descriptor spans/hashes and source/destination IDs are retained. One concrete
binding is Artisans' Stone Hill destination u32 at WAD0x927C94.

These are source-observed surface bindings, not a complete portal graph:
balloonists, Return Home, rendering/path companions, collision reachability,
guards, and new transition/save behavior still require their own closure.
Ordinary declared writes cannot enter these descriptors, even their type byte.
`ProtectedSourcePortalDescriptors` means these source spans are excluded from
the declared write footprint. It does not establish that changed headers,
component pointers, geometry or overlay code still reach those descriptors; that
is native payload/consumer semantics, expressly outside this precondition.
Any nonempty portal-retarget intent fails: a caller declaration is not proof that
the actual native consumer and companions were correctly changed.

## Regression and evidence

Run the source-free suite without a disc:

```sh
dotnet run --project src/Spyro.Editor.NativeLevelSlotOwnershipSmoke -c Debug
```

Run the same suite plus source binding, read-only:

```sh
dotnet run --project src/Spyro.Editor.NativeLevelSlotOwnershipSmoke -c Debug -- --source "Spyro the Dragon (USA).bin"
```

Markers are `NATIVE_LEVEL_SLOT_OWNERSHIP_SMOKE_OK` and, for source mode,
`NATIVE_LEVEL_SLOT_OWNERSHIP_SOURCE_OK`. Source-free tests include synthetic
physical aliases against selected and shared resources, invalid decimal IDs,
slot/save duplicate ownership, immutable request snapshots, source-space identity,
write conflicts and boundaries, native portal pointer/type/length failures,
retirement/egg capacity, deterministic order, and atomic refusal. A tiny disposable
non-retail input proves the real source factory rejects synthetic inputs without
touching them; it is removed by the suite.

The source-backed golden reserves all35 retail slots and70 disjoint declarations
(one existing overlay extent and one initial-music row each), retaining all29
portal descriptors. It proves this ownership precondition, **not** actual payload
composition or a new published ROM. Plan SHA:
`c7406bfce9e60e346f5d488b01a68a2c35af7491ab4e5b7f4249e9f386c41a32`.

The first focused Debug run passed with zero build warnings/errors:65 source-free
checks/50 expected refusals and76 combined source-backed checks/52 refusals.
Additional hostile parser/null/budget tests, the real tiny-input source refusal,
the plan golden assertion and portal-span naming clarification were added after
that run. The parent then rebuilt the final Debug project with zero warnings/
errors and ran the complete source mode:86 checks/60 expected refusals passed,
including those additions and the same plan golden. The integrated Release
repository gate is recorded separately after the source freeze.

No existing exporter, schema, candidate or byte golden is changed by this additive
contract. New independent-level publication remains blocked pending one integrated
identity/resource allocation producer with typed table growth, normal portal and
return routing, callback/loader/music/save closure, exact readback and separate
runtime re-entry/death/save/audio acceptance.
