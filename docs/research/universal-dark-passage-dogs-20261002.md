# Dark Passage dog transitions

The composer now includes both forms of the Dark Passage dog and its actual
spawned attack class. The three native class-changing stores select the imported
models and handlers even when destination class numbers differ. Placement keeps
the original state, collision and scalar properties while allowing position and
heading changes.

Nine original variants with no lantern reference can compose in a foreign level.
The seven variants linked to a lantern remain refused: their environmental
lighting dependencies still need an adapter. Native controls retain those links,
and native deletion cannot leave a surviving dog pointing at a removed lantern.

Integrated source verification passed 2,489 checks: all sixteen original variants,
the nine moved imports with forced class aliases, seven foreign-placement
refusals, native controls, linked deletion and mutated-input guards. Source
identity, copied instruction flow and native collision/reward helpers are checked
before rewriting the three class constants. Unrelated placements bypass this
adapter and do not trigger an unnecessary source lookup.

The integrated report is `dark-sentinel-integrated-r1.json`; exact instruction
owners and the frozen delivery are under `coverage/darkpassage35-ownership-r1`.

This establishes source ownership and composition only. Native transformation,
attacks, defeat, reward and persistence remain untested for this change. Particles

not promoted by the class-transition adapter. No release package was produced.
# Linked lantern groups and attack effects

The ordinary placement path now expands a linked lantern and its creatures as
one editable group. Foreign copies retain native actor glow, timers and creature
transformations through the source's negative terrain-lighting branch. They do
not change the destination terrain lighting; the Add Object details explain
this directly. Native Dark Passage with unchanged terrain keeps its original
lighting controls. Required members must retain their relative positions.

Dark Passage projectile effects 1/13 have source-owned implementations for Dark
Hollow, original Peace Keepers and the Town Square engine used by cleared Peace
Keepers. Equivalent effects stay native. Missing effect 13 receives one copied
updater followed by one native manager update. Conflicting copied owners refuse.
Other host effects, collection stars and audio listening remain unverified.

Integrated checks pass 338 lantern, 189 projectile and 2,489 existing dog checks;
the App builds with zero warnings/errors. Source-only combined worker checks
also cover Magic, boar and Haunted adapters. Native testing is pending on the
immutable r5 candidate under `coverage/darkpassage-projectile-cleared-candidate-r5`
in `work/universal-finish-20261002`. Neither a copied model nor these source
checks establish gameplay acceptance.
