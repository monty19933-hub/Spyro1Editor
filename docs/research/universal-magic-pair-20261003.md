# Magic Crafters pair: ordinary export integration

The original selector-2 druid pair (Magic Crafters rows 12/13) now uses the
ordinary placement-group and export path into untouched Dark Hollow. Either
member can be the authored root. Common translation, unique editor identities,
retired ledger entries and lifetime slots 0 through 127 are supported. The
source yaw and relative member transforms remain required.

An aggregate certificate authenticates the source behaviors, native collision
helpers, bounded movement, actor/pod allocation, assets, final scene, executable
patches and independently assembled relocated code. The final scene is derived
from the authored placement; admission does not require one fixed image or pose.
The original placement reproduces the previously tested r5 data and overlay.

Integrated validation passes 8,754 source/composition checks, including actual r5
disc readback. The Dark Passage regression passes 2,489 checks, moved-boar
regression 7,111, and the Release App builds with zero warnings or errors.
The smoke is registered in the source-aware regression runner.

Native r5 evidence shows charge defeats awarding two and five gems, contact
damage, death/respawn, prevention of a duplicate reward after respawn, and the
final seven-gem HUD. It does not show a flame defeat. The r5 candidate uses
lifetime slots 0/1; higher lifetime mappings have source/scalar evidence, not
new native gameplay or memory-card reload acceptance. Audio was muted.

Remaining exclusions are explicit: other destinations or selectors, edited or
cleared Dark Hollow, native removals, terrain/music/header/asset edits, mixed
active imports, multiple pairs, individual transforms and arbitrary yaw. These
change the certified native dependencies and still refuse export. This is a
bounded integration milestone; universal gameplay is unfinished.
