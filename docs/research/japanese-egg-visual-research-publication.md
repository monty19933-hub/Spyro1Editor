# Fixed two-F5 Artisans visual research package

`NativeJapaneseEggResearchCandidatePlan` is a separately named private visual
experiment, not a normal exporter. Its only factory accepts exact JP BIN, exact
USA BIN and source-bound USA CUE paths. It accepts no caller placements, actor
counts, mode/profile choices, arbitrary patch arrays, approval flags or receipts.

The factory invokes the source-issued `NativeJapaneseEggArtisansPlacementPlan`
itself: egg-a=(72704,47104,6656), yaw32; egg-b=(72704,49152,6656), yaw96. Both
retain original opaque row4F mode1. The placement certificate is evidence of
flat dry indexed support and native actor-center separation, not final collision
volumes, route safety, camera visibility or gameplay acceptance.

The plan retains that exact placement, the actual two-row integration, actual
render-admission object, and the source-issued normal-load/synchronous-stack
memory report. The render plan must reference the same integration object and
the memory report must bind its exact plan fingerprint. The ordinary
`RequireNativeActivation` refusal remains unchanged. The fixed research path
does not claim complete transient/IRQ/renderer peak safety or rendered pixels.

grammar is now extracted into `NativePackedResearchEntryComposer` behind two
closed entry points. The old `NativeWizardResearchPackedEntryComposer.Compose`
keeps its signature and Dark13/14 guard. The Artisans9/10 entry point requires
an actual source-certified integration; it cannot take caller replacement bytes.

EXE and ISO mechanics. Its private constructor is reached only by typed Wizard

logical raw-sector writer and whole-image physical readback. Exact both-endian
ISO fields use the already-existing checked `PatchRoot` helper. The original
complete WAD is reconstructed by inverse before staging.

The F5 profile changes only WAD entries9/10 and the existing integration's EXE
copy-buffer patch. Overlay growth800 plus model growth1000 yields1800 bytes

three owned zero-gap sectors are promoted. All unrelated WAD entry bytes and
the raw-sector complement are preserved; complete raw readback covers every
sector, not just named payloads.

The existing closed `NativeWizardResearchPublicationBinding` gained one sealed
F5 role; the existing staging, output lease, exact companion verification and
new-only `ExportArtifactTransaction` are reused unchanged. The resolver also
protects the Japanese donor path. F5 has distinct image/CUE/receipt, stage and
lease names. There is no generic callback/profile-controlled publisher.
