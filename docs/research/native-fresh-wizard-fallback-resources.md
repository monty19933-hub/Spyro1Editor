# Source-bound fresh Wizard fallback resources

This adds an actual detached resource revision for Town classes0E/0F/10, the
native repeat-reward alternatives. It is not an installed fresh Wizard body,
save owner, audio-compatibility certificate, or gameplay approval. Existing
Resource/Scene/Staging/export APIs and their old goldens remain unchanged.

## Implementation and ownership

`NativeId65FreshWizardResearchFallbackResourcePlan.CaptureAsync` takes the
original BIN and an actual prior `NativeId65FreshWizardResearchResourcePlan`.
It retains that object and its actual Compilation/Family ancestry. Equal hashes
from another resource cannot rebind this plan. Capture checks the entire
original image before and in finally, including true EOF; there are no output
paths, caller-supplied packages, model lists, authorization booleans or hashes.

Three complete original Town registrations are appended after the entire prior
17800-byte model allocation, preserving the Wizard's6CC-byte read-ahead pad:

| Class | New offset | Source package bytes | Registration extent |
| --- | --- | --- | --- |
| 0E | 17800 | 7EC | 7EC |
| 0F | 17FEC | 78C | 78C |
| 10 | 18778 | 330 | 888 |

All numbers in this table are hexadecimal. Used models end18AA8; a separate558
zero pad rounds the complete stream to19000. All four original roots remain
unchanged. Shared PETE already owns numeric models104/105; no guessed extra
local registration is inserted.

Class0E is a simple negative-header model, not animated texture grammar. Its
161 fixed-eight-byte faces and three relocation fields have their own bounded
shape check. The actual renderer reads the next0F package's first eight bytes
`01000000FFFFFFFF`; preserving these source-owned adjacent bytes is necessary
even though they lie beyond the simple package.

The animated0F/10 descriptors remain byte-identical. Their texture rectangles
need67 new strided pixel/CLUT spans totaling1120 bytes, plus four existing
same-source two-byte Town aliases. New spans must occupy certified zero
background, not merely pixels whose current value happens to be zero. Aliases
must retain their actual Town provenance. All other VRAM bytes, old models,
the complete8FC data components and65800 audio bank remain unchanged.

## Next composition boundary

The new host must retain the actual P1 scene and this actual fallback revision
through their common prior resource. Transfer bytes must be derived from this
revision's upload; its VRAM residue is no longer interchangeable with old
staging even though the audio bank is identical. A new public staging-version
adapter is not needed merely to compose these actual owners.

Global1F's occupied mapping, complete callbacks/render/particle lifetimes,
dynamic/stack peak, persistent reward history, native incoming/re-entry and
hardware tests remain separate obligations. In particular0E/0F/10 availability
does not prove that repeatedly spawned rewards or numeric actors cannot exhaust
the pool. No previous output scope is widened by this source-only revision.
