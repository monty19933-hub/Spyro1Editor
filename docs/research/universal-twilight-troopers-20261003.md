# Twilight Harbor soldiers in Dark Hollow

Ordinary Add Object and export now support all ten original Twilight Harbor
class 0x93 variants and all four class 0x94 variants in Dark Hollow. Paths and
activation rectangles follow the placed actor's translation. Repeated placements
receive separate mutable properties and persistent editor identities. The source
activation conditions, animation defaults, linked dynamic objects, models and
sounds remain intact.

The adapter authenticates the distant flash and explosion producers before
copying their behavior. Existing equivalent destination effects stay native;
missing effect 13 receives one source-owned updater. Combining Dark Passage and
Twilight copies of that updater still refuses in either placement order. Other
destination families remain unverified and are not unlocked by these checks.

Integrated Release verification passed 4,431 focused composition, mutation and
readback checks, 189 Dark Passage regression checks, 102 source-free checks and
115 regression-runner checks. The App built with zero warnings or errors. The
separate source-instruction controls cover 81,946 actor, 40,768 particle and 600
world-input checks; these are not emulator playtests. Particle controls use
authenticated helper semantics and do not prove native pool exhaustion.

Task evidence is under `work/universal-finish-20261002`. Integrated reports are
`twilight-integrated-r2.json`, `twilight-dark-regression-r1.json` and
`twilight-sourcefree-r1.json`. The detailed owner ledger, native test route and
immutable first candidate are under `coverage/twilight-9394-r1`.

Native gameplay verification is pending: visibility, movement, attacks, defeat,
rewards, respawn and save persistence are separate acceptance work. No release
package was produced from this checkpoint.
