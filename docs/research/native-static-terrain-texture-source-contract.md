# Native static terrain texture source contract

This stage issues original-source texture resources, not a fresh textured
level. `NativeStaticTerrainTextureSource` and the neutral
`NativeStaticTerrainTextureLayout` are new, isolated seams; no ordinary
texture exporter or fresh untextured producer is changed.

Destination allocation, HQ/close rendering, runtime and publication remain
unapproved. No candidate is generated by this project.

## Source identity and supported records

The private issuer opens the exact USA image, requires length661547040 and
SHA256 `fc866b2a02e010a6658f8af2de28bb3001eb33513e5924af014e35643c6dee37`
before and after capture, and parses actual WAD/subfile/metadata owners.
Selection is restricted to the35 retail data entries and native ID0..127;
invalid selectors refuse before opening the source.

The existing native scene control scanner must prove that the selected
record is neither an animated/scrolling destination nor an animation source.
Its complete scene hash must match this capture. This is bounded scene-program
evidence, not permission to transplant arbitrary level behavior.

The source handle binds original image, WAD entry, complete donor-data hash,
local ID, complete184-byte record hash and code-owned interpretation profile.
Same local ID does not imply the same source identity or destination slot.

Both actual donor scenes contain empty8-byte full-record-animation and
scrolling components. Their indexed LQ art differs, not just their labels.
Dark T0 has32-pixel close tiles; Gnasty T0 has16-pixel close tiles. Rotated
Gnasty T12 is deliberately outside this first canonical-orientation subset.

The neutral decoder retains all23 eight-byte descriptors: two LQ aliases,
one HQ-leading LQ alias, four normal tiles and sixteen close tiles. LQ is
4bpp32×32, with16-byte pixel rows and32-byte×16-row distance palettes. Normal
and close tiles are8bpp, with full512-byte CLUT rows. All strided rectangles
must remain in the original0x80000-byte right-half VRAM upload, not its SPU
tail. The three LQ aliases must be byte-identical. All returned bytes are
detached; the neutral decoder never becomes source authority.

## Native direct-LQ boundary and the failed bound

Original EXE LBA53875 has length0x66000 and SHA256
`a533d75cab8afaae6107ec35a02a9a5fe979a92c7c955f9cf1ee50f693a1b998`.
Runtime PC converts to EXE file offset by subtracting0x8000F800.

The native loader80012D58..80012DA8 binds separate LQ/HQ tables with a
16-byte/168-byte stride. The fresh triangle's existing flag0x80 makes
80027264 branch to80027310, bypassing both normal and close enqueue blocks.
Native direct packets use `(id & 0x7F) * 16`; nonnegative material selects
the textured path, while0xFF retains the old untextured path. Textured GT3
advances0x28 bytes rather than untextured G3's0x1C: two emitted triangles add
24 packet bytes per pass. This is not a full-frame or RAM budget.

The first free test run exposed an incorrect generalization: arbitrary
positive clip values do **not** guarantee16 palette rows. Clip1/depth0 and
clip129/depth128 both select row16 despite being visible. Both remain explicit
tests executing the actual packet instructions. No seventeenth palette row
is silently assumed and no failing input is removed.

The corrected conditional bound uses the actual native default0x8000.
EXE80012CB4+0x14, file0x34B4, bytes
`008002340780013c605720ac0880013ccc8522ac`, SHA256
`126c3d68a117fc390d8ff0fb09e492f75c07409a49c0f1a409eca2f2346063a4`,
stores0x8000 to g800785CC. Renderer800267A8..B4 loads it through
g785A8+0x24. Fade preparation80027334..40 executes `srl t5,s5,2` in its
branch delay; fixed0x80 excludes the separate flag1 addition. For this
default and visible depthSum<32768, positive phase is at most4064, hence
palette row0..15. A future fresh allocator/body must explicitly require this
native clip contract; source record issuance alone grants no clip-state
authority. A bounded direct-store search is not proof against all possible
indirect runtime writes.

Normal/HQ/close consumer frontiers are identified but not approved: normal
queue80027688, record addressing8002826C and800283F8; close queue8002857C,
record addressing80028E74 and80029210. Keeping the complete record preserves
those resources without claiming their full rendering path is tested.

## Regression and replay

The isolated smoke project has source-free and read-only-source modes.
Its independent bounded scalar machine executes source branch/load delays,
LQ loader/base, clip initialization/preparation, packet selection, descriptor
arithmetic and packet advance. Synthetic self-tests check delay semantics.
ADD/SUB intentionally wrap: CPU overflow traps, COP2/GTE, GPU rasterization
and real RAM are not emulated.

```sh
dotnet run --project src/Spyro.Editor.NativeId65StaticTerrainTextureSmoke -c Debug
dotnet run --project src/Spyro.Editor.NativeId65StaticTerrainTextureSmoke -c Debug -- \
  --source 'Spyro the Dragon (USA).bin'
python3 src/Spyro.Editor.NativeId65StaticTerrainTextureSmoke/source_texture_fixture_oracle.py \
  'Spyro the Dragon (USA).bin'
```

The Python oracle independently reads MODE2 sectors, checks source hashes
before/after, and compares the C# fixture bytes against six exact EXE windows,
two additional instruction windows and both complete donor records. It does
not invoke an editor DLL or write output files.

`_local/research/fresh-native-textures-20260906/`. Intended missing-type RED
and clean Debug compilation were observed; the initial free failure and raw
oracle success are retained. The corrected Debug build completed in1.38s with
zero warnings/errors; source-free mode passed383 checks, and source mode
passed31 additional checks (414total). This includes sealed/private source
