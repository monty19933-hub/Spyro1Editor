# Guarded admission plus Artisans egg lifecycle

September 27, 2026. This source-only composition joins the separately tested
card-admission and egg-lifecycle owners. It is not installed in R08 and does
not implement native custom saving, inventory X/X or required-for-100% hooks.
Disc publication and gameplay results must be recorded separately.

## Closed composition

The profile retains the fixed two identities, ordinary slot0 and ledger at
801FF600 from the admission research disc. It owns card WAD entry2, Artisans
overlay9 and data10. The original-source EXE must be identical for both
ancestors. Only the Artisans copy-anchor pair is merged into the admission
EXE; complete EXE and all three entry inverses remain required.

The existing lifecycle factory remains unchanged by default. Its separate
guarded factory charges an additional800-byte guard capacity before the
bounded linker fixed point and final model/scene/row projection. The existing
10000-byte overlay ceiling is not raised. Neither stale row addresses nor an
unaccounted appended code block is accepted.

For a bound row, both pre-visual suppression and post-visual collection require
the A00 reservation, Ready phase, nonzero admitted epoch, matching native
controller/slot/marker, Artisans normal gameplay and the exact projected scene,
model, row-table, dynamic-base and callback roots. The gate has no stack frame,
calls or stores. The full nested and caller-stack interval must fit inside the
native top-stack reservation. Unbound canonical F5 rows retain their visual
route without reading the custom ledger.

Refusal skips the bound egg's visual update and collection logic; it does not
retire the native row or rewrite the renderer. An unavailable ledger therefore
does not fabricate collection progress or hide the egg as if it were earned.

This authenticates the current tuple and expected source geometry, not every
possible engine transition or interrupt. The epoch is opaque provenance after
the card overlay unloads, not an independently authenticated live session token.
Incoming native caller frames already exist before the guard; rejection cannot
repair an already-invalid frame. IRQ/reentrancy and whole-engine lifetime remain
unproved. CardWrites, RuntimeVerified and normal Create BIN approval remain false.

## Regression contract

The dedicated CPU probe executes the actual Begin, native poll, SHA/envelope
validation and Ready publication before replacing the card overlay with the
Artisans phase. It does not manually seed Ready state. The scene load boundary
is modeled, not real CD I/O. Tests then exercise seeded first-identity
suppression, second-identity pickup, dirty/generation bookkeeping, restored-scene
suppression, native reset, wrong save/scene/stack refusals and canonical F5.
Original-source runs also execute the Artisans callback and draw-list rebuild.
These are CPU/source checks, not emulator pickup or durable save evidence.
