# Shared bounded selected-material allocator

The internal neutral `CompileSelected` adapter accepts one through128 complete
records with contiguous IDs0..N-1. It snapshots the fixed upload before caller
iteration and copies each complete record/VRAM source at its yield boundary.
It shares the existing exhaustive upload ownership and GPU allocation kernel.
The public two-record adapter keeps its validation order, refusal strings,
allocation order and output bytes. The old two-face metadata grammar is closed.

This does not capture original sources, change any document/UI eligibility,
admit Mobys, issue a body/disc plan or authorize publication. Successful neutral
N1/N3 fixtures are not source-backed or in-game evidence.128 is an input bound,
not a promise that128 records fit real native GPU/data allocations.
