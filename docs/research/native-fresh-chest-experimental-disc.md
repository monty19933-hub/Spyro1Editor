## Explicit smoke routes

The Authoring smoke supports `--chest-source ORIGINAL_BIN ORIGINAL_CUE` for
in-memory/source checks. `--chest-experiment ORIGINAL_BIN ORIGINAL_CUE NEW_DIRECTORY`
is a separate explicit private-artifact mode. It creates only new named files,
verifies the actual BIN, reopens and fully inverses it, rechecks originals, then
writes a receipt and CUE last. Failed artifacts are preserved. This manually
invoked smoke assumes no concurrent mutation of its private destination directory;
it does not claim the editor publisher's full exclusive-directory transaction.
Neither mode silently rebuilds or changes the preserved editor or normal project.
