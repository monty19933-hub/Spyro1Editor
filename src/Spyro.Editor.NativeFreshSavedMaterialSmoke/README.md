# Saved two-static-material compilation smoke

The internal `NativeFreshSavedMaterialCompilation` binds an actual saved
schema-2 aggregate, with zero placements and two retail source descriptors, to
the existing selected direct-LQ Texture → Staging → Body → Disc factories.
It retains exact ancestor references and the whole canonical document. It is
not a candidate, writer, UI integration, long Store lease or runtime approval.

```sh
dotnet build src/Spyro.Editor.NativeFreshSavedMaterialSmoke -c Release
dotnet src/Spyro.Editor.NativeFreshSavedMaterialSmoke/bin/Release/net10.0/Spyro.Editor.NativeFreshSavedMaterialSmoke.dll
dotnet src/Spyro.Editor.NativeFreshSavedMaterialSmoke/bin/Release/net10.0/Spyro.Editor.NativeFreshSavedMaterialSmoke.dll --source /absolute/path/original.bin
```

Default mode opens no game source and retains only tiny test-owned project files.
Source mode additionally captures genuine original-source plans and measures
complete physical afterimages without writing them. Both modes retain their
tiny fixture roots on success and failure; neither deletes unknown owners.
There are no publish, candidate-output, UI, emulator or normal-export modes.

Markers are `NATIVE_FRESH_SAVED_MATERIAL_FREE_OK` and
`NATIVE_FRESH_SAVED_MATERIAL_SOURCE_OK`. The explicit `SavedMaterialProbe=Api`
build contains only the missing-type probe used before the new Core type was
added; normal builds default to all tests and reject unknown probe values.

Coverage includes actual saved/raw Snapshot conflicts; cooperating Save exclusion
by a held read guard without falsely excluding detached compilation; strict schema/placement/
mixed-color refusals; exact reference ancestry and legitimate own reissuance;
same-source reuse without cross-slot allocation aliasing; returned canonical
copies; static-source and geometry exclusions; held plus current named original
final checks; early/late callback and cancellation failures; and independently
attempted final raw-Snapshot/close accounting. Callback fixtures cannot supply
an issuer, native result, or replacement stream.

The embedded golden metadata is the frozen independent source oracle from
`_local/research/dark-wizard-native-closure-20260906/saved-material-bridge-tests-r01.wztv4B/`.
Its four A rows explicitly inherit prior pinned `NativeId65TexturedDiscSmoke`
oracle values; its new A/heading128/music20 row was reconstructed independently
before Core implementation and independently replayed by Root. The complete
new afterimage is `2533ee961f13e43db03b08f221921cb60e35465e662e51bf221e6c096eb75b70`
with 1253 changed raw sectors and an executed inverse to the original.

Valid saved animated, controlled, rotated, mixed-color or placed-Wizard intent
is preserved when this compiler refuses it. The old `8C8 → A38` grammar is not
widened. The existing fixed-a research Candidate still rejects this selected
factory even when native bytes match. No general texture portability, source
catalog certification, HQ rendering, saved publication or gameplay is inferred.
