# Source-issued one/two-Wizard composition

This detached backend stage joins the existing persistent append/placement
producers to the existing Dark Hollow resource, behavior and death-reward
composers. It does not publish a candidate, modify an original image, change
ordinary export/UI acceptance, or accept project/save history.

The new entry point is `NativeDarkHollowWizardResourcePlan.CompileWithAppendPlacementAsync`.
Its internal scene revision retains the **actual** append, placement and ledger
ancestors. Equal scene bytes with different family identities, or even an equal
ledger recaptured into a different append object, cannot be cross-paired.
No public count, hash, receipt or approval label grants source authority.

The bounded profile accepts one or two active, source-issued Wizard Peak
level33/T6 roles. The legacy one-Wizard APIs, public serializer shapes and output
bytes remain intact. Both paths use the same original-address scene payload and
shared resource/layout/linker implementation; code, models, animation8, textures,
sound and particle resources are installed once, not once per actor.
