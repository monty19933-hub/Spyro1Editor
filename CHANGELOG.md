# Spyro Editor Beta V2

Beta V2 focuses on keeping projects safe, making failures understandable, and promoting only the enemy replacements that passed real DuckStation testing.

## What's new

- Projects, settings, backups, update downloads, and generated output now live outside the replaceable editor installation.
- A one-time Beta V1 import prompt copies old saved edits and custom assets without moving the old folder or overwriting conflicts.
- The editor can notify you when the next numbered beta is published. The update window shows this changelog, creates a verified project snapshot, and accepts only the exact GitHub package whose identity and SHA-256 digest match.
- Build Safety now identifies the affected Moby and lets you double-click an issue to load its level, select it, and center the current camera on it.
- Same-level terrain texture swaps preserve source-verified four-corner near/fade tint data in private native color slots, carry the donor's exact collision property, survive save/reload, and persist Undo. The retained Artisans ground-to-water proof uses the correct horizontal pool visual.
- `Browse All Game Textures` now exposes the 19 genuinely native-unreferenced static texture records as explicit art-only donors. They replace the shared target record while preserving every target face's texture ID, native material/semitransparency bits, descriptor ABR/alpha controls, tint, editor material label, and collision behavior. The 22 animation-source diagnostics and 4 controlled face-less destinations remain visibly blocked. Art-only mode survives save/reload/Undo and `Create BIN` repeats the complete-record and exact-readback proof without inventing a donor face/property key.
- Level maps now reject false source-scene prefixes and Gnasty's World's source-proven two-sector unterminated suffix that appeared as detached geometry outside later levels. Legitimate separated regions in Dark Passage and Dream Weavers remain, and Map/Fly 3D again preserve the native per-face terrain colors. Stone Hill's real ocean geometry remains intact and is colored from its correct native records.
- Map and whole-level Fly `Fit`/Reset now default to **Complete Scene**, with every captured HP face visible and material-rendered. Spyro's HP colors are decoded from the retail two-bank layout—one contiguous four-byte table-1 bank followed by one contiguous four-byte table-2 bank—instead of the former incorrect interleaved-pair interpretation that produced cyan/pink terrain. The cache contract is bumped so all 35 overlays rebuild. Camera-less Map uses physical table 2 as its stable overview endpoint; local Game Camera keeps camera-dependent DPCS and native HP/LP selection. No face is hidden or converted to outline-only mesh, and `Create BIN` is unchanged.
- Fly 3D keeps the coherent high-detail editor renderer in both overview modes. The incomplete native-distance/LP compositor no longer activates on the first movement from an impossible whole-level aerial camera, which previously exposed forced-horizon triangles as a broken green field. The native-distance path remains covered by focused game-scale research smokes.
- Fly navigation now stays responsive without changing the current overview's face set or replacing native textures with flat averaged colors. Movement uses a lower-cost native-material interpolation tier, with full-detail interpolation restoring automatically after input settles. Selected and edited terrain remain full-detail, and this performance tier never enables the broken LP renderer.
- Fly 3D height positioning is now four times finer: Q raises and E lowers the camera by 64 world units per key press instead of sharing the 260-unit planar movement step. W/A/S/D speed is unchanged, making indoor positioning easier without slowing ordinary travel.
- Fly 3D now uses source-decoded native texture art, including the exact load/default state of all 70 animation or scrolling destinations across the 35 retail levels. Format 9 retains both normal/close HQ tiers, every HQ descriptor's raw PSX555/STP texels and local ABR mode, the real 32x32 4-bpp LQ base, both LQ descriptors, and all sixteen raw distance-palette rows. Every PNG and raw sidecar is hash-bound to the same initialized source state, and incomplete or mixed sets fail closed. At game-scale cameras, the bounded native compositor combines LP Gouraud faces, the selected LQ descriptor/palette row, eligible HQ descriptor tiles, the opaque `0xFF` material sentinel, and STP-gated ABR 0-3 writes in one RGB5 framebuffer. It now uses Spyro's exact native 4x4 GPU dither/quantize stage before ABR, the retail HP/LP base-bucket equations—including the correct HP renderer-flag mask—and the coarse LP → all HP bases → normal HQ → close HQ FIFO phases inside the 0x800-entry world ordering table. `Fit`, edited terrain, custom PNG imports, and texture relocations retain the complete legacy preview until their final raw material payload can be proven. This is the level's initial state, not live animation playback, and it does not yet claim retail GTE projection/color interpolation, clipping, HQ tile-local subdivision/depth, or full ordering-table traversal.
- The next HQ renderer layer is now smoke-locked without overstating the live preview: exact normal/close queue selection, signed midpoint and packed-color rules, all four retail quad/triangle 4/16-tile topology tables, and exact GT3/GT4 tile-bucket equations are available over explicit integer GTE-depth lattices. They remain intentionally unwired until Fly 3D can supply native fixed-point SXY/SZ/FLAG/NCLIP provenance instead of floating-point projected corners.
- The reproduced Peace Keepers travel crash is blocked before export when a linked portal sky replacement exceeds its native storage capacity.
- Red, green, blue, yellow, and purple gems now use matching color variants of the same gem icon.
- Every one of the 380 Mobys that previously reached a generic tree, Gnorc, actor, or target fallback now resolves to an audited themed icon. Three generated low-poly atlases cover 40 exact families across all 35 levels, including the final Beast Makers banner, Crocodile, Rescue Fairy, Super Grenadier, campfire, cage, lever, lantern, balloon, and Metalhead boss set; linked controls and unrelated transport parts remain excluded.
- The verified Green Wizard routes for Blowhard, Magic Crafters, and Wizard Peak are available through the guarded replacement workflow.
- Artisans can now add one runtime-verified native gold Key + Locked Chest pair through the normal saved/undoable object workflow and `Create BIN`. DuckStation proved the correct Key and chest textures, native Key-gated opening and sound, six gem objects totaling +10 treasure, one-shot cleanup, and persistence. The standalone Key remains universal; broader Locked Chest support stays level-profile-gated: 13 levels already contain native class `0x00AE` but still need focused add-path validation, 16 other regular levels need their own handler/model/texture profiles, and all five flight layouts remain blocked for true appends.
- Selected objects have direct Z-axis controls, and supported fly-in and portal placement tools retain their existing safety checks.

## Updating from Beta V1

Beta V1 did not contain an updater, so V2 must be downloaded manually. On the first V2 launch, choose **Import Beta V1 Project**, then select the old extracted Beta V1 folder. The editor copies the project data into protected storage and leaves the original folder untouched.

Beginning with Beta V2, ordinary fixes do not create update prompts. Users are notified only when a deliberate next release such as **Spyro Editor Beta V3** is published.
