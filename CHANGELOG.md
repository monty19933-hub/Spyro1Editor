# Spyro Editor 1.0.7

## Changes since Spyro Editor 1.0.6

- Fix blocking fit calculations when selecting an object or source version in the full Add object catalog.
- Keep search, selection and Close responsive while checks run in the background. Share repeated checks and limit concurrent work.
- Ignore stale selection results and cancel queued checks when the browser closes. Placement still requires a successful exact fit check.

All 1.0.6 gameplay features and restrictions are retained. Universal Moby gameplay remains incomplete. The Mac package is Developer ID signed but not notarized; the Windows package has not been run on Windows.
