# Spyro Editor 1.0.8

## Changes since Spyro Editor 1.0.7

- Double-click an object in Inspect removal plan to move the editor camera to it.
- Add a Remove object button to that inspector. Removed entries disappear from the list, the camera stays put, and the normal Recovery undo remains available.
- Prevent an old inspection window from removing objects after the editor changes levels.

The object-picker responsiveness fix and all existing gameplay restrictions are retained. Universal Moby gameplay remains incomplete. The Mac package is Developer ID signed but not notarized; the Windows package has not been run on Windows.
