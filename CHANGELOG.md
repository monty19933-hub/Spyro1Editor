# Spyro Editor 1.0.5

## Changes since Spyro Editor 1.0.4

- Add a visible Save button and Cmd/Ctrl+S for current-level object and terrain
  edits. Saving blocks overlapping commands and waits before closing.
- Use command menus for File and More so arrow-key navigation does not run an
  action before selection is confirmed.
- Bring placed-object search and Undo last removal into easier reach; group
  height controls under Position & snapping and detailed checks under Export checks.
- Clarify Open Game, Quick Add and placement instructions; keep low-level object
  identities in detailed views and retain full export results behind Details.
- Keep every source version available in Add Object, including lists over 200.
  Background capacity updates preserve the selected version, and stale removal
  plans cannot apply to a different selection.
- Add clearer empty search states and keep placement buttons visible in smaller
  object-browser windows. Native export and gameplay remain unchanged.

# Spyro Editor 1.0.4

## Changes since Spyro Editor 1.0.3

- Add placeable teal gems worth 50 and rainbow gems worth 100 under
  Collectibles → Gems, using the existing USA source disc.
- Make both gems twice the normal size, with bright facet colours, idle
  sparkles and the native collection burst and rising value display.
- Include both values in editor totals, native collected treasure and level
  targets, with ordinary memory-card collected-state persistence.
- Support both gems in retail and fresh level composition with exact capacity
  checks, normal save/reopen, duplication, removal and distinct viewport markers.
- Keep the original five gem values and enemy/chest reward selectors unchanged.
- Add native source-owner, save identity, numeric popup and particle lifecycle
  checks. Level capacity still applies; see the supported-scope guide.
- Fix normal Create BIN asking for a Japanese disc for USA gem variants.
- Preserve original objects when reopening saved additions whose legacy
  indices overlap an existing object, and retain their collected identities.
