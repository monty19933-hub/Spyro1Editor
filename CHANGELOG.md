# Spyro Editor 1.0.6

## Changes since Spyro Editor 1.0.5

- Add dragon-statue colour selection to the object editor, with saved and exported native colours.
- Expand guarded cross-level enemy groups and preserve their linked terrain, collision, effects, rewards and player reactions.
- Restore Magic Crafters druid exports after the shared model-alignment fix. The Artisans pair has fresh native combat, Nestor rescue, gem collection, card save and cold-load verification.
- Fix imported replacement-orb resources and dynamic effect capacity in the verified Alpine examples.
- Retain textured terrain editing, recoverable Start Blank, portal routing, eye-free eggs, bright 50/100 gems and the shared editor workflow.
- Keep unfinished Alpine group-one rendering disabled. Unsupported combinations still report their dependency or capacity limits before export.

This local stable-channel checkpoint is ready for editing and testing within the supported scope. Universal Moby gameplay across every type and level remains unfinished. The Mac package is Developer ID signed but not notarized; the Windows package has not been run on Windows. No new full-campaign acceptance is claimed.
